Strudel zu programmieren. Es gibt viele verschiedene Möglichkeiten, den gleichen
Beat in Strudel zu schreiben.

:::tip
Manche Rhythmen sind etwas hektisch, wenn man die standardmäßigen 30 Zyklen pro
Minute verwendet, probiert dann
```js
setcpm(80); // oder 60 oder so
```

Oder geht höher, wenn Euch danach ist!
:::

## 4 On The Floor

<VexFlow code={`(VexFlow, factory, score) => {
    const system = factory.System();
    const hhhh = () => score.beam(score.notes("G5/8/m, G5/m", { stem: "up"}));
    const bd = () => score.notes("F4/q", { stem: "down" });
    const bdsd = () => score.notes("(F4 C5)/q", { stem: "down" });
    const sd = () => score.notes("C5/q", /*{ stem: "down" }*/);
    system.addStave({
        spaceAbove: 1,
        voices: [
          score.voice([hhhh(), hhhh(), hhhh(), hhhh()].flat()),
          score.voice([bd(), bdsd(), bd(), bdsd()].flat()),
        ],
      })
      .addClef("percussion")
      .addTimeSignature("4/4");
  }`} />

## 4 On The Floor (Halftime)

<VexFlow code={`(VexFlow, f, score) => {
    const system = f.System();
    const bd = 'f/4',
      sd = 'c/5', cs = 'c/5/x2',
      hh = 'g/5/x2',
      sp = 'f/5/x2',
      lt = 'a/4', ht = 'e/5',
      rb = 'f/5/d2', rd = 'f/5/x2';
    const voice0 = f
      .Voice()
      .addTickables([
        f.StaveNote({ keys: [bd, hh], duration: '4'}).addModifier(f.Articulation({ type: 'ah' }), 0),
        f.StaveNote({ keys: [bd, hh], duration: '4'}).addModifier(f.Articulation({ type: 'ah' }), 0),
        f.StaveNote({ keys: [bd, sd, hh], duration: '4'}).addModifier(f.Articulation({ type: 'ah' }), 0),
        f.StaveNote({ keys: [bd, hh], duration: '4'}).addModifier(f.Articulation({ type: 'ah' }), 0),
      ]);

    system.addStave({
        spaceAbove: 1,
        voices: [
          voice0
        ],
      })
      .addClef("percussion")
      .addTimeSignature("4/4");
  }`} />

"Ghost notes" sind leicht/leise geschlagene Töne (meist Snare Drum). Probiere den Befehl

:::tip
Strudel hat zwar eine "Ride", aber keine "Ride Bell". Für die Ride Bell schlägt
man das Ride-Becken an dem gewölbten Teil in der Mitte an.

Wir können aber zusätzliche Töne aus dem Internet laden. Probier mal folgendes
vor Deinen Rhythmus zu schreiben:
```js
samples({
  rb: 'GSCW Drums Kit 2 Samples/V01-Rbell-22.wav',
  rd: 'GSCW Drums Kit 2 Samples/V01-Ride-22.wav',
}, 'https://raw.githubusercontent.com/gregharvey/drum-samples/master/');
```
Damit bekommst Du eine passende Ride und Ride Bell!
:::
